# 🎀 OUMAYMA STUDY SPACE

A beautiful, modern student productivity dashboard built for 1ère Année Génie Informatique (S1 — SEC 2 / GR 4).

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-8-646CFF?logo=vite&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-3-06B6D4?logo=tailwindcss&logoColor=white)

## ✨ Features

- **Dashboard** — Overview with motivational quotes, today's schedule, and urgent tasks
- **Emploi du temps** — Full weekly timetable (SEC 2 / GR 4) with add/edit/delete
- **Study Planner** — Task management with priorities and status tracking
- **Mes Matières** — 7 subjects with chapter progress tracking
- **Notes & Résumés** — Create and manage study notes
- **Pomodoro Timer** — Focus timer with session statistics
- **Quiz & Exercices** — Interactive quizzes across all subjects
- **Exam Prep** — Exam preparation dashboard
- **Statistiques** — Visual progress and study analytics
- **Smart Assistant** — AI-powered study helper
- **Settings** — Theme toggle (light/dark), data export/import, reset

## 🎨 Design

- Elegant feminine academic aesthetic with soft pink, lavender, and purple tones
- Animated sakura petal background
- Responsive layout for desktop, tablet, and mobile
- Light and dark theme support
- Smooth transitions and hover effects

## 🛠️ Tech Stack

- **React 19** — UI framework
- **Vite 8** — Build tool and dev server
- **Tailwind CSS 3** — Utility-first CSS framework
- **Lucide React** — Beautiful icon library
- **LocalStorage** — Client-side data persistence

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/oumayma-study-space.git
cd oumayma-study-space

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
